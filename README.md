# T.E.C-OS 节点原型 MVP v2

把 T.E.C-OS（案件 A-001）的交互从「命令行 + 超链接」改成 **Nodes 式节点图**：**拖拽 = 合成**。

单文件、零依赖、真实 A-001 数据内嵌。双击 `index.html` 就能玩。**没有改动 `chrisutada.github.io` 仓库里的任何文件。**

> 界面主题：复古单色系统风（灵感来自 PC-98 时代 OS / 早期 Windows 界面）——米白 + 墨色的单色世界，直角细黑框窗口、衬线 bitmap 字体；唯一的彩色是台灯点亮时的暖黄光晕。主题纯 CSS 实现，交互逻辑与类名钩子未动。
>
> **桌布 = 暖象牙纸**：三层叠加做纸感 —— 细颗粒（`feTurbulence` 噪波，`soft-light` 混合，均值中性不压暗底色）＋ 零星深色纸屑（阈值化噪波，`multiply`，覆盖率约 1.3%）＋ 大面积色斑（三个 radial-gradient 表现纸张不匀），最后一层极淡的边缘压暗。噪波以内联 SVG data-URI 内嵌，无外部图片依赖。调参入口集中在 `:root` 的 `--paper-grain` / `--paper-fleck` 与 `#stage` 的 `background-*` 一组声明里。

## v2 相对 v1 的改动（核心）

| | v1（错的方向） | v2 |
|---|---|---|
| 拖拽 | 移动节点位置 | **拖 A 到 B 上 = 组合使用** |
| 布局 | 手工自由摆放 | 力导向自动布局，节点不用摆 |
| 场景 | 双击「下钻」，独立页面 | 双击**展开**，里面的东西掉到画布上、永久留在图上 |
| 合成 | 无 | 有：产出新节点 / 新场景，并**消耗**参与节点 |
| 密码 / 选项 | 无 | 全在节点上：双击木盒弹密码框输 0321、双击抽屉弹出左/右抽屉节点 |

## 操作

| 操作 | 效果 |
|---|---|
| **拖动节点** | **移动位置**（跟手）。松手落在空白处就停在那，并**锁定**，之后自动布局不再挪它 |
| **拖到另一个节点上松手** | **组合**。命中则产出新节点/新场景并消耗参与节点；节点自己被弹回原位 |
| **拖到已折叠的场景节点上** | **把节点放回现场（收纳）**：节点存进该场景（保留连边），展开场景时取回 |
| 场景节点左上角 ⤓ 小按钮 | **批量收回**：把归属该场景、未钉住的内容物一键收回（钉住的保留在画布上） |
| 节点右下角「捕」小按钮 | **捕获 hiddenClue**：提取该节点数据里隐藏的线索（生成线索节点 + CAPTURE 窗口 + 归档日志）；有未捕获线索的节点按钮**常显**，其余悬停才显示；真结局配方的前置 |
| 桌面图标（左侧竖排，可拖动换位） | 四个功能入口统一为 OS 桌面图标：**单击 = 选中，拖动 = 移动，双击 = 打开应用窗口**，**拖节点到图标上 = 直达功能** |
| 开场适性测试（首次启动） | `APTITUDE // 调查员适性测试`：登记姓名 → 三道五感倾向题 → 生成 `INVESTIGATOR // 调查员证`（**竖版挂绳工牌式**三区卡纸：黑色头部色带 + 身份区【居中的 120×120 编号确定性像素头像 + 姓名/编号/等级】+ 倾向区 + 签发区【日期 + 旋转核准印】，证件为全界面唯一圆角元素）→ 确认领证后窗口缩入**顶栏徽标**；徽标点击 = 回看证件 / 重新测试；localStorage 持久化，之后启动直接进入案件 |
| ◈ 推演器 | 双击开 `INFERENCE // 推演器`（逻辑阵列）：拖线索节点入五个感官槽位（类型不符拒绝），或直接把线索拖到图标上自动归入对应槽；`[ SYNC_MATRIX_INFERENCE ]` 推演——阵列线索与某结局配方精确匹配即触发**结局演出**（全屏步进放映，点击跳过，真结局有真名揭示） |
| ▤ 档案 | 双击开 `ARCHIVE // 档案`（原 GOTO）：列出"听说过"的场景（已展开 / 在画布 / 文本里见过 `[loc:]` 标签或被标题点名），点击召唤到画布并居中视野；拖场景节点到图标上 = 直接前往。孤岛场景（如「门的后面」）的解锁入口 |
| ▣ 证物袋 | **拖节点到图标 = 随身收纳**（离开画布，保留连边，角标显示件数）；**双击 = 清单窗口**（`STORAGE // 证物袋`，标注来源场景），**点清单项 = 取回**到袋子附近的画布位置 |
| ◉ TEC | **双击 = 对话窗**（`TEC // 对话`，历史滚动 + `[ 交谈 ]` 按钮推进上下文提示）；**拖节点到图标 = TEC 分析**（反馈进对话窗）。有新提示时角标 + 呼吸灯 |
| ≡ 日志 | **双击 = `SYS_LOGS // 因果追踪` 窗口**（原右侧日志栏，默认开启）：全部叙事/操作归档；**窗口关闭时新日志在图标上累加计数徽标**，打开自动清零 |
| 记忆场景（6月2日 / 7月4日）首次展开 | **MEMORY 放映卡**：叙述 + 在场角色的场景台词逐行播放（做旧黑标题栏样式），可拖动、× 关闭 |
| 双击场景节点 | 展开该场景内的物品 / 角色 / 线索节点，永久留在画布；**首次展开弹出叙事卡片**（`SCENE_FEED` 系统窗口，归档进 SYS_LOGS）；**双击已展开的场景 = 折叠收纳**（内容物隐藏，被用到别处的节点会留下，再双击恢复） |
| 双击物品节点 | 执行它的主命令（打开 / 查看 / 使用）。**台灯 = 点亮 / 熄灭**（节点发光 + 画布光晕）；**抽屉 = 直接把「左侧抽屉」「右侧抽屉」弹成画布上的场景节点**；**木盒 = 弹出 `LOCK` 密码窗** |
| 双击角色节点 | **逐句对话**：`DIALOG` 系统窗口气泡（阅后即焚，归档进日志）；节点右上角紫色角标显示未读句数 |

> 所有浮窗（叙事卡 / 对话气泡 / TEC 对话窗 / 密码窗 / 各应用窗口）统一为**系统窗口样式**：标题栏（`SCENE_FEED //`、`DIALOG //`、`TEC //`、`LOCK //`、`STORAGE //`、`ARCHIVE //`、`INFERENCE //` 命名），**整个窗口都可拖动**（× 按钮和输入框除外），用右上角 **× 关闭**（点空白不会收起，方便对照文本继续探索）。

| 拖 黑胶 / 唱针 → 唱机 | 对应唱机的 `useItem` 命令（放入黑胶 / 播放音乐） |
| 双击线索节点 | 捕获线索 |
| 单击节点 | **选中并聚焦邻居 + 打开 `DETAIL // 节点详情` 检查器**：无关节点和连线被淡化（顶栏「聚焦选中」开关可关闭）；详情检查器选中即开、取消选中/点空白/× 即关。**它是信息表，不是第二个阅读器**：只放场景出入口、线索**感官类型**、物品**来源场景**、角色对话进度等结构信息，并提供「**[ 重看场景叙事 ]**」按钮把叙事卡叫回来。**同一段描述只在别处都看不到时才在这里出现**（如：有命令的物品、线索、角色）—— 详见下方「去重规则」 |
| 空白处拖动 / 滚轮 | 平移 / 缩放画布 |
| **自动布局 / 适应窗口 / 撤销 / 重置** | 清掉锁定重新排版 / 缩放到可见 / 回退一步 / 回到初始 |
| **合成消耗**（左上开关） | 关掉后道具不消失，方便反复试 |
| 检查可达性 | 报告有多少场景没有文本入口 |

> **移动与组合不抢同一个手势**：靠"松手的位置"区分 —— 落在空白处是移动，落在别的节点上是组合。
> 想重新排版，点「自动布局」即可清除所有手动位置。

## 去重规则（一段文本只在一个地方出现）

三个界面各管一类信息，互不逐字复读：

| 界面 | 职责 | 不再做的事 |
|---|---|---|
| 🗔 **SCENE_FEED 叙事卡** / 💬 提示条 | 承载**正文**（场景叙事、物品描述、对话台词） | — |
| ≡ **SYS_LOGS 日志** | 只记**一行事件**（谁对谁做了什么） | 不再镜像浮层全文 |
| ▤ **DETAIL 详情窗** | 只放**结构信息** | 不再复读别处已有的描述 |

判定规则很机械：**只在「这段文本别处已经看得到」时，才从详情窗移除** —— 去重，但不丢内容。

| 节点 | 描述文本的出口 | 详情窗 |
|---|---|---|
| 场景 | 叙事卡（正文唯一出口） | 不放正文，给「[ 重看场景叙事 ]」按钮 |
| 物品（**无**命令） | 双击 → 提示条 | 不放 |
| 物品（**有**命令） | 双击跑的是命令，描述没有别的出口 | **保留** |
| 线索 | 捕获后在详情窗可读，无其他出口 | **保留** |
| 角色 | 一句话身份，无其他出口 | **保留** |

> 叙事卡被关掉后正文不会失联：单击场景节点 → 详情窗底部「[ 重看场景叙事 ]」重新放映。
> 日志里对应的只有一行：`〔场景〕标题：叙事卡已放映`。

## 数据里本来就有这套机制

原作的合成逻辑**已经写在案件数据里**，v2 只是把它图形化了：

```jsonc
// 目标.presentReactions[工具Id]  —— 拖「工具」到「目标」身上
"ITEMS_bd": {                          // 绷带
  "presentReactions": {
    "ITEMS_jd": {                      // 剪刀
      "text": "剪刀一点点剪开缠绕整具尸体的绷带……",
      "results": { "scene": "SCENES_lhsdst" }   // → 陆珩松的尸体
    }
  }
}

// 角色同理：char.itemReactions[工具Id] / char.reactions[工具Id]
"CHARS_zs": { "itemReactions": { "ITEMS_rxbs": { "text": "是我……将这把匕首插进了陆老师的腹部……" } } }
```

查找顺序：目标有反应表 → 反向（工具自己有反应表）→ 目标的 `useItem` 命令正好需要这个工具（如 黑胶 → 唱机）→ 目标是场景时扫描场景内物品/角色。
**同一个 id 只查一次，命中就打住**；没命中的组合会画成灰色虚线留在图上，避免无脑穷举。

## 已知取舍

- **消耗规则是我定的默认值**：数据里没写「用完之后道具是否消失」。默认双方消耗，`REUSABLE_TOOLS`（手电筒 / 黄铜钥匙 / 唱针 / 唱机）永不消耗；与角色对话不消耗。左上开关可整体关闭。如果原作语义不同，改一个数组即可。
- **台灯的点亮是纯视觉状态**（节点上的 `lit` 标记 + 画布光晕），不进历史以外的任何游戏逻辑：可随撤销回退，重置后清除。
- **密码窗弹出时锚定在节点下方的世界坐标上**，画布平移 / 缩放时跟着节点走；它也是系统窗口，整窗可拖动挪到任意位置（拖动节点本身时窗口不跟手，× 关闭）。
- **对话队列 = 默认队列（talkQueue / defaultTalks / lines）+ 角色来源场景的 sceneTalks 拼接**，逐句推进、可撤销；队列耗尽后重复最后一句，进度不再增长。
- **叙事卡只在场景首次展开时出现**（开局也会显示起始场景的入场叙述）；撤销回到未展开状态后再展开会重播。气泡与叙事卡都是锚定在世界坐标上的临时浮层，**拖动节点时不跟随**，用右上角 × 关闭（点空白不会收起）；叙事文本不沉淀为持久节点，**正文只活在卡里**——日志只留一行 `〔场景〕标题：叙事卡已放映`，卡片关掉后用详情窗的「[ 重看场景叙事 ]」重新放映。
- **TEC 不是画布节点，而是桌面上的 ◉ 图标（屏幕坐标，不随画布平移缩放）**。提示上下文 = 最近展开的场景（`lastScene`）：该场景的 `sceneTalks` 逐句给完后，继续交谈轮换 `defaultTalks`；场景提示可撤销，默认轮换不进历史。拖节点到图标上 = 查 `itemReactions`/`reactions` 给出分析，命中不消耗节点，未命中记入 tried 避免穷举；对话历史（`tecHistory`）是页面会话级的，不进快照。
- **桌面图标位置不进撤销栈，重置不回位**（刷新页面才恢复左侧竖排的默认站位）；节点拖放的图标命中固定优先级 bag > tec > infer > goto，保证多个图标矩形重叠时行为确定。
- **调查员信息存 localStorage（key `tec_investigator`）**：不可用 localStorage 的环境（如无头验证 stub）自动退化为内存态——当次会话有效，刷新后重新测试。重置案件（`btn-reset`）不会清除调查员身份；只有证件回看窗口里的「重新测试」会清档重来。
- **详情 / 日志是静态外壳的系统窗口**（`#detail-body` / `#log` 元素 id 与内容结构不变，选择器与日志捕获照常工作），可见性由引擎内布尔维护（无头环境兼容）。**详情检查器没有独立图标**：生命周期绑定选中态（选中即开、取消即关，× = 取消选中），重置时收回关闭；日志窗关闭期间的新日志在 ≡ 图标上计数。
- **场景折叠按 `homeScene` 归属 + 边连通性做 fixpoint 收敛**：归属该场景且没有边连到"会保持可见"节点的内容物才被隐藏；**手动摆过（pinned）的节点不参与折叠**，线索节点不记 homeScene、永不隐藏。折叠状态进历史，可撤销。
- **聚焦选中只是视觉淡化**（节点加 `dim`、非相关边降透明度），不影响任何交互逻辑；点空白即退出聚焦。所有浮窗（叙事卡 / 对话气泡 / TEC 对话窗 / 密码窗 / 应用窗口）统一为系统窗口样式：标题栏拖动、右上角 × 关闭；点空白不会收起浮窗。
- **收纳 ≠ 折叠**：折叠是视觉开关，收纳是玩家主动把节点移出画布存进场景（场景=现场仓库，画布=线索板）。收纳的节点**保留全部连边但暂不绘制**，取回后关系网原样恢复（不会留下悬挂的 tried 边）；收纳会把节点的归属场景更新为目标场景并解除钉住；单个拖放收纳允许 pinned 节点（玩家明确意图），批量收回跳过 pinned；场景节点（loc）不可被收纳。
- **证物袋与场景收纳共用同一套 stored 机制**（袋中节点 `storedIn === "BAG"`）：同样保留连边、可撤销、不计入可见数；`bagFrom` 记录来源场景用于清单标注。两者的取回路径不同——场景收纳在展开场景时批量取回，证物袋在清单里逐个点取。
- **「听说过」= 已展开 ∪ 在画布 ∪ 已见文本中的 `[loc:]` 标签或场景标题点名**：玩家见过的文本（合成/命令/密码/TEC 分析的成功与失败消息）都进 `seenTexts`（上限 200 条），**不随撤销丢失**（知识一旦获得不回退）；GOTO 窗口据此给出场景索引。捕获对无 hiddenClue 的节点记 `cap:` tried，防止无脑穷举。
- **逻辑阵列只记线索 id**，线索节点本身留在画布上（归槽不消耗）；槽位/结局状态进快照可撤销。结局演出是**步进状态机**（浏览器里 setTimeout 自动推进、点击立即跳过、无头测试用钩子手动推进），真结局未达成前名称显示为「真名捕获：？？？」。
- **记忆场景列表是 A-001 的硬编码常量**（`SCENE_MEMORY = 6月2日 / 7月4日`），换案件时需要更新。
- 力导向布局是自动的，但**手动拖过的节点会被锁定**（`n.pinned`），自动布局不再动它 —— 想统一重排点「自动布局」。
- 命中测试按「离光标最近」选目标，多节点重叠时不会选错。
- 条件跳转 `conditional` 需要线索已捕获才放行，捕获入口在双击线索节点。
- 起始场景直接是「植物学家的花园」：原作的 `startScene` 是「T.E.C-OS」引导场景，教学的是命令行玩法，在节点版里没有意义，因此跳过（它会成为可达性检查里的孤岛，属预期）。
