# 开场流程设计：开始界面 + TEC 引导式开局

> 日期：2026-10-24
> 性质：玩法/流程设计文档（未定稿实现计划）。
> **执行记录（2026-10-24）**：**第 0–6 幕已全部落地**。
> 第 0 幕：全屏开始界面（红色恶魔 + 开始 / 继续 / 设置 / 退出）、点击恶魔晃动、继续按存档启用、开始覆盖旧档确认、设置内全屏切换。
> 第 1 幕：开始后进入空白教学桌面 —— 隐藏 app 图标栏 / 撤销 / 调试 / 面包屑 / 调查员证章 / 案件窗控件；TEC 是普通窗口，可拖动 / 关闭 / 最小化，开场白后生成「调查员」节点。
> 第 2 幕：拖「调查员」到 TEC 窗体任意位置 → 获得线索「调查员」；双击人物「调查员」节点 → 出现证件节点（双击线索不生成节点，TEC 口头指回人物）；把证件拖给 TEC → 获得线索「调查员证」。错拖由 TEC 口头纠正，不出系统 toast。
> 第 3 幕：图标栏首次出现，解锁线索册 / 证物袋 / 推演器，TEC 图标按普通 app 常驻；TEC 只提醒物品可进证物袋、线索可进线索册，收纳是可选的，不收纳也能直接双击推演器进入下一幕；收纳规则与正式案件一致。
> 第 4 幕：玩家双击推演器打开桌布，双线索配方（「调查员」+「调查员证」），长按执行者 2.5 秒；蓄力线为核准红，配方不齐时 TEC 在桌布内提示。
> 第 5 幕：新 `CertWin` 只收姓名 / 编号 / 日期 / 照片，无测验、无 sense；姓名必填，编号与日期自动生成；复核窗可更换照片，T.E.C 核准印章为红色。
> 第 6 幕：案件地图解锁并弹窗，A-001 可进入、A-002 锁定；进入后完整桌面解锁，画布出现「植物学家的花园」并自动写档。
> `IntroWin` 仍保留给旧存档 / 绕过开始界面的启动路径，正常「开始」已不再进入。
> 地位：**取代现有 `IntroWin` 的「姓名→测验→头像→证件」强制流程**（呼应 `UX_FLOW_PLAN.md` G9 与「直接领证、撤销测验、sense 不上证件」的已定结论），
> 同时把 G1 的「分步首局引导」从文案条升级为**玩法本身**——教学不靠读，靠做。

---

## 1. 流程总览

```text
开始界面（恶魔 + 开始/继续/设置/退出）
   │ 开始
   ▼
空白桌面：无 app 图标，画布中央是 TEC 窗体（常驻）
   │ 出现「调查员」节点
   ▼
① 拖「调查员」到 TEC ──→ 获得线索「调查员」      【教学：拖给 TEC】
   │ 双击线索
   ▼
② 双击人物「调查员」──→ 出现物品卡「调查员证」   【教学：双击激活】
   │ 拖物品卡给 TEC 分析
   ▼
③ TEC 分析物品卡 ──→ 得到线索「调查员证」        【教学：TEC 分析】
   │ 此时解锁三个 app：线索册、证物袋、推演器
   ▼
④ TEC 提醒收纳（可选）：物品 → 证物袋，线索 → 线索册；也可直接推演
   ▼
⑤ TEC 教学推演：线索拖入推演器 → 长按推演        【教学：桌布 + 长按】
   │ 推演成功
   ▼
⑥ 获得「调查员证」→ 填写证件：姓名 / 编号 / 日期 / 照片
   │
   ▼
⑦ 案件地图 app 出现并直接弹窗，TEC 提示选择一个案件
   │
   ▼
进入所选案件（完整桌面解锁）
```

每一步的教学目标都内嵌在动作里：**玩家亲手做过一遍的东西，不需要日志再教一遍**。

## 2. 分步详述

### 第 0 幕 · 开始界面

- 全屏开始界面，视觉主体是一个**红色恶魔**（像素形象，72px）。**互动演出（2026-10-24 终稿）：点击只有晃动反馈**（表情气泡上过一轮又撤下——克制优先）。
- 开场节奏（已实现）：黑场自检行 → 卡片淡入落定 → 恶魔连框缓进（淡入+上浮）→ BGM 淡入（Air_Bach，开始/继续后淡出关闭）→ 标题逐字（120ms/字）→ 按钮逐行缓进（串行、间隔明确）。卡片高度全程恒定（按钮始终占位只淡透明度）。恶魔待机只有呼吸浮动。
- 下方四个按钮：**开始 / 继续 / 设置 / 退出**。
  - 开始：新建调查（有旧档时应确认覆盖，呼应 `UX_FLOW_PLAN.md` K1 的危险操作确认原则）。
  - 继续：读最近存档直接回到桌面（无档时置灰禁用）。
  - 设置 / 退出：常规。
- 气质定位：开始界面是全游戏唯一允许「跳出桌面隐喻」的画面，可以比桌面更风格化；但配色纪律不变（红色恶魔属于内容形象，不算 UI 彩色）。

### 第 1 幕 · 空白桌面与 TEC

- 进入后是**空白桌布**：左侧没有 app 图标栏，顶栏只保留品牌与证章（调试入口不收）。
- **TEC 以窗口形态常驻**（已定）——教学期 TEC 是主角，它在这里说话、接收拖拽、做分析；窗体即「角色」。**TEC 和普通 app 窗口完全同构**：开场居中，可拖、可关、可最小化，关掉后可从左侧 TEC 图标叫回。
- TEC 开场白（已定）：**「欢迎来到 TEC，你将开始领取你的调查员证，以便展开工作。」**——一句话同时交代了地点、目标和流程终点。
- 开场白后，桌面上出现一个节点：**「调查员」**（人物节点，就是玩家自己——由 TEC 从档案中调出，即开场白里的「领取」动作）。

**当前实现（2026-10-24）**：
- 「开始」→ `Desktop._begin_tutorial()`：清空案件运行时并进入空白教学桌面，不启动 `_start_slice()`、不加载起始场景。
- 隐藏 app 图标栏、撤销 / 调试、面包屑、调查员证章、案件窗关闭 / 最小化；顶栏只剩 `T.E.C-OS` 品牌。证章要等第 5 幕证件签发后才出现，此时不显示是刻意的。
- TEC 是普通 app 窗口：开场时居中，但可拖、可关、可最小化；关掉 / 收起后左侧会出现 TEC 图标，点图标即可叫回。开场白走 TEC 自己的打字机。
- 「调查员」以 `char:CHARS_INVESTIGATOR` 人物卡生成在桌面左下，作为第 2 幕「拖给 TEC」的起点。
- 第 2 幕的拖拽 / 纠错台词已接入（见下）；教学期 `_tutorial_active` 状态由整套 0–6 幕共用。

**容错口径（已定）**：教学期玩家拖错目标（物品拖到线索册、线索拖到证物袋、节点拖到空白处等），
**不用系统的拒收 toast，由 TEC 亲口纠正**，语气统一为引导式——「这个不归那里，换一个试试」
「线索要去线索册」一类。教学期的错误反馈 = TEC 的下一句台词，不是系统的报错。

### 第 2 幕 · 三个核心动词的教学

| 步骤 | 玩家动作 | 系统反馈 | 教会的东西 |
|---|---|---|---|
| ① | 把「调查员」节点拖到 TEC 窗体上 | TEC 分析，产出**线索「调查员」** | 拖拽 + 「节点可以交给 TEC」 |
| ② | 双击人物「调查员」节点 | 出现**证件物品卡「调查员证」**；双击线索不生成节点，TEC 指回人物 | 双击 = 激活/展开，且证件属于人物 |
| ③ | 把物品卡拖给 TEC 分析 | TEC 解读，得到**线索「调查员证」** | TEC 分析链路完整一遍 |

- TEC 的引导台词随步骤推进，只指下一步（不一次性灌输三个动词）。
- 每步完成后动作立即有产物（线索/物品卡），形成「做 → 得到 → 好奇下一步」的节奏。

**当前实现（2026-10-24）**：
- 教学使用独立迷你案件 `cases/tutorial/case.tres`：调查员人物、两条线索、一张「调查员证」物品卡；正式案件 A-001 的数据不被污染。
- ① 把「调查员」拖到 **TEC 窗体任意位置**（标题栏、正文、头像都算）→ TEC 分析 → 左上阶梯生成线索「调查员」，带「新」角标。该整窗落点规则对正式案件同样生效。
- ② 双击**人物「调查员」**节点 → 生成证件物品卡「调查员证」；连线从**调查员人物**出发到证件，不从线索出发。双击线索不会生成任何节点，TEC 会口头指回人物。TEC 接着提示把证件拖过去。
- ③ 把「调查员证」拖给 TEC → 分析完成，生成线索「调查员证」；这条线索从证件连出，TEC 状态改为「登记完成」。
- 拖拽松手后的回位补间期间，连线逐帧跟随卡片，回位结束再补一次重绘，不会停在落点或指向旧位置。
- 新卡片上画布时立刻重画连线；教学期跳过 0.2s 的卡片 pop 淡入，保证卡片与连线同帧出现，不再有「线慢一拍」。
- 所有拖拽落点共用一层 2px 虚线框（`ui/DropOutline.gd`，压在窗口 / 图标之上）：窗口和 TEC 在可见窗框外 4px（`PAD - 4 = 10`），图标 / 卡片贴外框，TEC 顶栏 chip 内缩 2px，推演桌布内缩 4px。拖到任意窗口、图标、TEC 或卡片上效果一致；移出或松手立即收起。卡片作为组合目标时也走这层虚线框，不再整块反白。
- 系统窗打开或被点击（标题栏或正文）都会提到浮动窗栈顶并成为当前激活窗；toast、拖拽虚线框、拖拽镜像、领证窗仍保持在最上层。选中节点时详情窗也会提到当前层，避免被 TEC / 后开的窗压住。
- 换案 / 教学进入正式案件会重建 `graph`；详情窗随运行时一起销毁重建，避免继续引用旧 graph 后「查不到节点而隐藏」。
- 教学期卡片不走力导向重排：位置固定为左下角阶梯，窄窗时自动收窄横向步长，避免钻到 TEC 窗体下面。
- 「调查员」人物节点带 `always_visible`：教学迷你案件没有场景上下文，拖拽收尾 / 收纳重算按普通人物规则会把它藏掉，这个标记让它在整个开场里稳定留在桌面。
- 错拖 / 在错误步骤双击 / 点 TEC，都由 TEC 用当前步骤的引导句纠正；收纳等常规操作沿用正式案件的系统提示。
- TEC 的底部提示与状态行按步骤切换；教学期不写案件进度，第 5 幕领证后写调查员证与一份「进入案件」的存档。
- 第 3 幕的三 app 解锁、第 4 幕推演、第 5 幕领证、第 6 幕选案均已接入（见下）。

### 第 3 幕 · app 解锁与收纳提醒

- ③完成后，左侧**图标栏首次出现**，一次性解锁三个：**线索册、证物袋、推演器**（伴随图标落位的小演出，如从左侧滑入）。
- TEC 教学收纳（可选提醒）：提示**物品卡可以放进证物袋**、**线索可以放进线索册**，但不强制；玩家直接双击推演器也能进入第 4 幕。

**当前实现（2026-10-24）**：
- `_tutorial_unlock_apps()` 显示图标层：`clue / bag / infer` 三枚从左侧 18px 滑入并淡入；TEC 图标也按普通 app 常驻。地图、档案、人物、日志继续隐藏。
- 收纳规则与正式案件完全一致：证物袋只收物品、线索册只收线索；错收、重复收、把容器拖进去都走正常提示。
- 收纳不是硬门槛：物品进袋、线索进册只是可选整理；打开推演器或直接把线索放上桌布就会从「整理可选」推进到第 4 幕。**不自动打开任何 app**，也不自动搬动线索。
- 玩家可把 TEC 拖到一边或最小化，给后续的桌布 / 线索册让出位置。

### 第 4 幕 · 推演教学

- TEC 教学推演（步骤⑤）：把线索从线索册（或画布）**拖入推演器桌布**，然后**长按执行者**进行推演。
- **推演配方已定：双线索**——需要「调查员」+「调查员证」两条线索同时上桌布才成立。
  相比单线索多教一步「多条线索上同一张桌布」，教学价值更高；TEC 的引导台词分两拍：
  放上第一条时说「还需要一条」，两条齐后提示「长按执行者，开始推演」。
- 推演成功的演出即「资格认证」的叙事化——玩家不是被发证，而是**推演出了自己的证件**。

**当前实现（2026-10-24）**：
- 教学迷你案件新增 `TUT_CERT` 结局配方：`CLUES_INVESTIGATOR` + `CLUES_INVESTIGATOR_CERT`，走现有 `GraphState.match_ending()`。
- 玩家双击「推演器」图标打开桌布；线索可从册子行拖上桌布，也可用行内「上桌布」按钮。TEC 不会被自动收起，挡住时由玩家拖开或最小化（TEC 行会明确提示）。
- 底边提示随进度切换：零条 / 一条「还需要一条」；两条「长按执行者，开始推演」。
- 配方不齐时长按只会出心碎表情，并在桌布底边写 TEC 的纠正句，不弹系统 toast。
- 长按蓄力的外圆 / 五芒星描线为**核准红**（`SPOT_DANGER`），静态虚线仍是墨黑。
- 推演成立后收起桌布与收纳窗，进入第 5 幕领证。

### 第 5 幕 · 领证

- 推演结束后获得「调查员证」，进入证件填写界面。
- 证件字段只有四项：**姓名 / 编号 / 日期 / 照片**（编号与日期可自动生成，玩家只填姓名、选照片）。
- **没有测验、没有 sense**（已定结论；sense 若日后参与玩法，选择放在后果发生的那一刻，不放开局）。

**当前实现（2026-10-24）**：
- 新窗体 `scenes/windows/CertWin.gd`（`ZR_CERT`，关闭 / 最小化隐藏，必须填完）：左侧表单 + 右侧证件预览。
- 表单四项：姓名（必填，空姓名抖动并提示）、编号（`Investigator.gen_id()` 自动）、签发日期（系统日期自动）、照片（执行者 / TEC / 档案照三选一）。
- 确认后 `Investigator.save_to()` 写入 `user://tec_investigator.json`，并在当前会话中刷新顶栏证章。
- 签发后点击顶栏证章打开复核窗（340×470）：证书 + 「更换头像」按钮完整落在窗内，不再溢出；「更换头像」打开 `PhotoWin` 三选一并写回证件。
- T.E.C 核准印章（领证预览 / 复核窗 / 旧 `build_cert`）改为**核准红**。
- 证件预览与旧的「查看调查员证」窗口都不再显示 sense；`IntroWin.build_cert()` 已删掉主导感官段落。
- 第 5 幕完成会额外写一份 A-001「进入案件」存档，保证此时退出后「继续」也能跳过开场。

### 第 6 幕 · 选择案件（已定）

- 领证完成后，**「案件地图」app 出现并直接弹窗**，TEC 同时告诉玩家：**选择一个案件**。
- 案件地图此时只有 A-001 可用、其余「锁定」，玩家的第一次点击自然落在唯一可选行上——
  「案件地图怎么用」也在做中学会，不需要另行说明。
- 选择后进入案件：完整图标栏解锁，画布出现起始场景「植物学家的花园」。

**当前实现（2026-10-24）**：
- 领证完成 → 地图图标解锁（与三枚收纳图标并列）→ 地图自动弹窗，A-001 行显示「可进入」，A-002 保持「锁定」。
- 地图第一次打开时把地图与 TEC 并排摆一次（地图左、TEC 右），避免 TEC 压住唯一可点的 A-001 行；之后就是普通窗口，玩家可自由拖动。TEC 状态改为「等你选案」，点击 TEC 只重复「在案件地图里选 A-001」。
- 点击 A-001 → `_finish_tutorial_to_case()`：装载正式案件 A-001、重置镜头到「适应窗口」、`_start_slice()` 生成花园起始节点、恢复完整图标栏 / 顶栏证章 / 撤销 / 调试 / 案件窗控件 / TEC 拖动与关闭按钮。
- 进入案件后立即 `_autosave()`；下一次启动「继续」直接回到案件桌面，跳过整段开场。
- 教学期的临时卡、TEC 窗、地图窗、桌布与收纳窗全部收掉；TEC 收起，可从左侧 TEC 图标重新打开。TEC 图标在应用栏解锁后与普通 app 一同常驻。

## 3. 与既有系统的衔接点

| 既有项 | 影响 |
|---|---|
| `IntroWin`（姓名/测验/头像/证件） | 正常开场不再进入；第 5 幕改由新 `CertWin` 承担（姓名/编号/日期/照片，无测验、无 sense）。旧 `IntroWin` 仅保留给 `--no-start` / 截图 / 旧测试；`build_cert()` 已删掉 sense 段落 |
| `UX_FLOW_PLAN.md` G1（首局分步引导条） | **由本流程取代**：教学内化为玩法，引导条不再为首局设计；若保留「当前目标」条，从正式进入案件后才开始用 |

## 4. 验收要点

- 首玩玩家不看任何文档，能从开始界面一路做到选择案件，无死路、无「不知道该干嘛」的停顿。
- 每一步只允许当前该做的动作；做错动作时由 TEC 台词纠正（「换一个试试」），不出现系统报错口吻的 toast。
- 教学期 TEC 与普通 app 窗口同构：开场居中，可拖 / 可关 / 可最小化；挡住桌布时由引导句提示玩家自己移开。
- 所有 app 都由玩家双击图标打开，窗口使用正常尺寸与位置；教学不自动打开、不自动搬动线索。
- 老玩家点「继续」直达桌面，不看任何开场。
- 领证界面只有四个字段，无测验、无 sense；签发后复核窗不溢出，并保留「更换头像」入口。
- T.E.C 核准印章、推演长按蓄力线使用核准红；其余界面仍守 1-bit 配色。
- 领证后案件地图自动弹窗，TEC 同步提示选案；选择后完整桌面解锁。
- 写盘失败不假装成功（沿用 G8 口径）。
- 开场各步骤可撤销性从简：教学链路是线性的，前进即推进，不需要撤销支持。
