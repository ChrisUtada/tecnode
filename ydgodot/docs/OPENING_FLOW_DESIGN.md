## 1. 流程总览

```text
开始界面（恶魔 + 开始/继续/设置/退出）
   │ 开始
   ▼
空白桌面：无 app 图标，画布中央是 TEC 窗体（常驻）
   │ 出现「调查员」节点
   ▼
① 拖「调查员」到 TEC ──→ 获得线索「调查员」      【教学：拖给 TEC】
   │ 双击线索
   ▼
② 双击「调查员」线索 ──→ 出现物品卡「调查员证」   【教学：双击激活】
   │ 拖物品卡给 TEC 分析
   ▼
③ TEC 分析物品卡 ──→ 得到线索「调查员证」        【教学：TEC 分析】
   │ 此时解锁三个 app：线索册、证物袋、推演器
   ▼
④ TEC 教学收纳：物品 → 证物袋，线索 → 线索册     【教学：收纳】
   ▼
⑤ TEC 教学推演：线索拖入推演器 → 长按推演        【教学：桌布 + 长按】
   │ 推演成功
   ▼
⑥ 获得「调查员证」→ 填写证件：姓名 / 编号 / 日期 / 照片
   │
   ▼
⑦ 案件地图 app 出现并直接弹窗，TEC 提示选择一个案件
   │
   ▼
进入所选案件（完整桌面解锁）
```

每一步的教学目标都内嵌在动作里：**玩家亲手做过一遍的东西，不需要日志再教一遍**。

## 2. 分步详述

### 第 0 幕 · 开始界面

- 全屏开始界面，视觉主体是一个**红色恶魔**（像素形象）。**互动演出已定：点击时恶魔晃动 + 头顶冒出表情**（表情内容/轮换规则待美术细节，技术上是「点击 → 位移抖动 + 表情气泡浮现消失」两件套）。
- 下方四个按钮：**开始 / 继续 / 设置 / 退出**。
  - 开始：新建调查（有旧档时应确认覆盖，呼应 `UX_FLOW_PLAN.md` K1 的危险操作确认原则）。
  - 继续：读最近存档直接回到桌面（无档时置灰禁用）。
  - 设置 / 退出：常规。
- 气质定位：开始界面是全游戏唯一允许「跳出桌面隐喻」的画面，可以比桌面更风格化；但配色纪律不变（红色恶魔属于内容形象，不算 UI 彩色）。

### 第 1 幕 · 空白桌面与 TEC

- 进入后是**空白桌布**：左侧没有 app 图标栏，顶栏只保留品牌与证章（调试入口不收）。
- **TEC 以居于画布中央的窗体形态常驻**（已定）——教学期 TEC 是主角，它在这里说话、接收拖拽、做分析；窗体即「角色」。
- TEC 开场白（已定）：**「欢迎来到 TEC，你将开始领取你的调查员证，以便展开工作。」**——一句话同时交代了地点、目标和流程终点。
- 开场白后，桌面上出现一个节点：**「调查员」**（人物节点，就是玩家自己——由 TEC 从档案中调出，即开场白里的「领取」动作）。

**当前实现（2026-10-24）**：
- 「开始」→ `Desktop._begin_tutorial()`：清空案件运行时并进入空白教学桌面，不启动 `_start_slice()`、不加载起始场景。
- 隐藏 app 图标栏、撤销 / 调试、面包屑、调查员证章、案件窗关闭 / 最小化；顶栏只剩 `T.E.C-OS` 品牌。证章要等第 5 幕证件签发后才出现，此时不显示是刻意的。
- TEC 用 `SysWindow.set_drag_enabled(false)` 固定在画布中央，关闭 / 最小化按钮隐藏；开场白走 TEC 自己的打字机。
- 「调查员」以 `char:CHARS_INVESTIGATOR` 人物卡生成在桌面左下，作为第 2 幕「拖给 TEC」的起点。
- 第 2 幕的拖拽 / 纠错台词尚未接入；教学期 `_tutorial_active` 状态已就位。

**容错口径（已定）**：教学期玩家拖错目标（物品拖到线索册、线索拖到证物袋、节点拖到空白处等），
**不用系统的拒收 toast，由 TEC 亲口纠正**，语气统一为引导式——「这个不归那里，换一个试试」
「线索要去线索册」一类。教学期的错误反馈 = TEC 的下一句台词，不是系统的报错。

### 第 2 幕 · 三个核心动词的教学

| 步骤 | 玩家动作 | 系统反馈 | 教会的东西 |
|---|---|---|---|
| ① | 把「调查员」节点拖到 TEC 上 | TEC 分析，产出**线索「调查员」** | 拖拽 + 「节点可以交给 TEC」 |
| ② | 双击「调查员」线索 | 出现**物品卡「调查员证」** | 双击 = 激活/展开 |
| ③ | 把物品卡拖给 TEC 分析 | TEC 解读，得到**线索「调查员证」** | TEC 分析链路完整一遍 |

- TEC 的引导台词随步骤推进，只指下一步（不一次性灌输三个动词）。
- 每步完成后动作立即有产物（线索/物品卡），形成「做 → 得到 → 好奇下一步」的节奏。

### 第 3 幕 · app 解锁与收纳教学

- ③完成后，左侧**图标栏首次出现**，一次性解锁三个：**线索册、证物袋、推演器**（伴随图标落位的小演出，如从左侧滑入）。
- TEC 教学收纳（步骤④）：让玩家把**物品卡放进证物袋**、**线索放进线索册**——两个动作各做一次，顺手教会「图标也是落点」。

### 第 4 幕 · 推演教学

- TEC 教学推演（步骤⑤）：把线索从线索册（或画布）**拖入推演器桌布**，然后**长按执行者**进行推演。
- **推演配方已定：双线索**——需要「调查员」+「调查员证」两条线索同时上桌布才成立。
  相比单线索多教一步「多条线索上同一张桌布」，教学价值更高；TEC 的引导台词分两拍：
  放上第一条时说「还需要一条」，两条齐后提示「长按执行者，开始推演」。
- 推演成功的演出即「资格认证」的叙事化——玩家不是被发证，而是**推演出了自己的证件**。

### 第 5 幕 · 领证

- 推演结束后获得「调查员证」，进入证件填写界面。
- 证件字段只有四项：**姓名 / 编号 / 日期 / 照片**（编号与日期可自动生成，玩家只填姓名、选照片）。
- **没有测验、没有 sense**（已定结论；sense 若日后参与玩法，选择放在后果发生的那一刻，不放开局）。

### 第 6 幕 · 选择案件（已定）

- 领证完成后，**「案件地图」app 出现并直接弹窗**，TEC 同时告诉玩家：**选择一个案件**。
- 案件地图此时只有 A-001 可用、其余「锁定」，玩家的第一次点击自然落在唯一可选行上——
  「案件地图怎么用」也在做中学会，不需要另行说明。
- 选择后进入案件：完整图标栏解锁，画布出现起始场景「植物学家的花园」。

## 4. 验收要点

- 首玩玩家不看任何文档，能从开始界面一路做到选择案件，无死路、无「不知道该干嘛」的停顿。
- 每一步只允许当前该做的动作；做错动作时由 TEC 台词纠正（「换一个试试」），不出现系统报错口吻的 toast。
- 教学期 TEC 窗体常驻画布中央，不被拖动教学打断、不被其他窗遮盖。
- 老玩家点「继续」直达桌面，不看任何开场。
- 领证界面只有四个字段，无测验、无 sense。
- 领证后案件地图自动弹窗，TEC 同步提示选案；选择后完整桌面解锁。
- 写盘失败不假装成功（沿用 G8 口径）。
- 开场各步骤可撤销性从简：教学链路是线性的，前进即推进，不需要撤销支持。
