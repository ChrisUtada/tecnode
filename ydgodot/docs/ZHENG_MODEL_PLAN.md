## 1. 模型总览

```text
原料（不是知识：不可分析、不上桌布、不上字段）
  物 = 物品（现有节点，天然物证）
  词 = 证言卡（对话/独白/回忆 首次完整播放 掉落）
        │
        ├── TEC 分析（origin = tec）──────┐
        └── 物 × 词 合成（origin = synth）─┴──> 证（唯一知识代币）
                                                    │ 五感 + origin
                    ┌───────────────────────────────┼───────────────────┐
              推演桌布（按五感收）          档案卡字段（只收证）        证据册（全收）
```

**三个消费口的守卫不变**：桌布按五感收、字段只收证、册全收——「证」一职多能但不模糊。
**人物线索**（档案卡集齐产出）= 第三种 origin：`deduce`（演绎），落地即已捕获。

## 2. 三类节点的定义与生命周期

### 2.1 物（物品，现有类型，不改类型只加身份提示）

- 现有物品节点原样保留（工具/点亮/容器等既有行为不受影响）。
- **身份提示**：被任何证据配方引用的物品，详情窗加一行「可用作证据原料」——
  否则玩家不知道哪些物品能当「物」用。
- 物品作为原料参与合成时**不被消耗**（证是「想出来的」，不是「炼出来的」）。

### 2.2 词（证言卡，新卡面、非新类型家族）

- **产出**：`DialogueDef` 新增结构化字段 `drops_evidence`（→ 词卡定义 id）；
  **首次完整播放完才掉落**（补全跳过打字不算首次完整播放），重播不重复掉落；回忆放映同规则。
- **字牌**：「词」（墨色反白，KindGlyph 槽位；卡面规格与现有节点卡完全一致，不新增形状）。
- **收纳**：进**证物袋**（讯问笔录与物品同夹）。
- **行为**：单击选中+详情；**不可**被 TEC 分析、不可上桌布、不可上字段、不可进线索册/证据册；
  唯一出路 = 与「物」合成。

### 2.3 证（唯一知识代币，接管旧「线索」全部职能）

- **属性**：`sense`（五感之一）+ `origin`（`tec` 分析 / `synth` 合成 / `deduce` 演绎）。
- **字牌**：「证」（同规格槽位字牌）。
- **产出**：
  1. TEC 分析物品/场景（原 `hidden_clue` 产线索路径整体更名为产证）；
  2. 物 × 词 合成（配方表 `EvidenceRecipeDef`：`item / testimony / evidence / sense / text`）；
  3. 档案卡字段集齐 → 人物线索（`origin=deduce`，落地即已捕获）。
- **消费**：推演桌布（按五感收）✅；档案卡字段（只收证）✅；证据册 ✅；
  拒收规则照旧形态（证物袋不收知识、TEC 不分析知识、对话窗只收人物）。

---

## 3. 合成规则（物 × 词 → 证）

- **签名配方**：物 × 词（物证要拿证词印证）；也允许 物×物、证×物 由配方表逐条定义；链深一案 2–3 层封顶。
- **合成不消耗**：物与词留在画布，只产证（产物在目标右下 `(60 + i*26)` 撒开 + pop + 「新」角标）。
- 匹配走 `ComboSystem` 证据配方段（无序对）；未命中照旧记 `tried` 虚线。
- 配方必须标注产出证的 `sense`——纳入可达性检查（推演配方所需感官必须全部可达，
  允许「某感官只能靠合成获得」的设计，但要有解）。
- **可靠性钩子**：配方可限定 tier（如「推翻不在场证明」必须 词×物 双原料）；
  纯「词」支撑的主张核对时 TEC：「他只说了这些——但话可以撒谎。」

---

## 4. 档案卡主张 → 核对 → 盖章（沿用已定的玩法层）

- **主张**：把「证」拖到关键字段行 + 词库选值（死因等）→ 字段进入待核对态（虚线框 + 小牌）。
- **核对**：TEC 批量核对（攒 2–3 条，不逐条判）；对 = **核准印章**（警示朱既有语义）；错 = 退回 + 不剧透提示。
- **完成**：关键字段全部盖章 → 掉落人物线索（`origin=deduce`，pop 入场，落地已捕获）；
  真名级触发 G14 提醒（强调青行首符号 + 反白行 + 打字机停顿，已落地）。
- 字段三层不变：自动（姓名/首次记录/照片）/ 半自动（身份、关联）/ 关键（死因、真名级，词库+证支撑）。
